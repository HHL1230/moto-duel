# MOTO DUEL — 2D 雙人越野機車對決

同機雙人（split-screen）2D 越野機車競速遊戲，使用 Python + pygame-ce。

## 特色

- **雙人同機對戰**：上下分割畫面，兩位玩家在同一條隨機賽道上競速
- **越野物理**：連續起伏地形、跳台、坑洞、空中翻滾與落地角度判定
- **障礙物**：巨石（撞擊減速或摔車）、泥沼（減速）、尖刺（直接摔車）
- **加成道具**：金幣（分數）、氮氣罐（加速資源）、護盾（抵擋一次傷害）、加速板
- **競技元素**：即時名次／落後距離、對手位置箭頭、賽程進度條、三回合制對決、落後方追趕補給
- **成就系統**：15 項成就，跨場次記錄於 `save_data.json`

## 執行方式

需先安裝 [uv](https://docs.astral.sh/uv/)。

```powershell
uv sync
uv run python -m motoduel
```

或直接雙擊 `play.bat`。

## 操作說明

| 動作 | 玩家 1 | 玩家 2 |
|------|--------|--------|
| 油門 | `W` | `↑` |
| 煞車／後退 | `S` | `↓` |
| 空中後傾／前傾 | `A` / `D` | `←` / `→` |
| 氮氣 | 左 `Shift`（或左 `Ctrl`） | 右 `Ctrl`（或右 `Shift`、`Enter`、`Num 0`） |

其他按鍵：

- `空白鍵`：開始對決／進入下一回合
- `A`：主選單查看成就
- `P`：賽中暫停
- `R`：重跑本回合
- `ESC`：返回上一層／離開遊戲

## 遊戲規則

1. 一場對決固定三回合，每回合為一條新隨機賽道（賽道長度 22000 px）。
2. 先抵達終點者贏得該回合；若無人完賽，以行進距離較遠者勝。
3. 首位完賽後，另一位玩家有 15 秒寬限時間完賽。
4. 回合勝場數較多者贏得整場對決；平手時比較累計分數。
5. 上一回合落後者，下一回合可獲得額外起始氮氣（追趕補償）；賽中落後超過 900 px 時氮氣回復加快。

## 計分

| 項目 | 分數 |
|------|------|
| 金幣 | +100 |

## 成就一覽

初嚐勝果、空中特技、翻滾大師、連環翻滾、拾荒者、氮氣狂人、完美無瑕、極速惡魔、逆轉勝、
跳台老鼠、越野老手、常勝軍、神速完賽、高分玩家、橫掃千軍。

## 專案結構

```
motoduel/
  config.py        # 物理、計分、畫面等全域參數
  terrain.py       # 程序化地形、障礙物與道具生成
  entities.py      # 機車物理模擬與特效
  achievements.py  # 成就定義與存檔
  render.py        # 字型、世界渲染與 HUD
  game.py          # 狀態機、輸入、賽事邏輯
tests/
  smoke_test.py    # 無頭煙霧測試（物理／互動／流程／繪製）
```

## 測試

```powershell
uv run python tests\smoke_test.py
```

測試以 SDL dummy driver 執行，不需開啟視窗，會驗證：地形可通行性、AI 全油門可完賽、
道具與障礙互動、翻滾計分、成就解鎖與存檔、三回合流程與各畫面繪製。
