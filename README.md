# MOTO DUEL — 2D 越野機車對決

2D 越野機車競速遊戲，支援**單人（對戰電腦）**與**雙人同機分割畫面**兩種模式，
使用 Python + pygame-ce，含程序化合成的背景音樂與音效。

## 特色

- **單人模式**：全螢幕視角對戰電腦車手，三種難度（簡單／普通／困難）
- **雙人同機對戰**：上下分割畫面，兩位玩家在同一條隨機賽道上競速
- **越野物理**：連續起伏地形、跳台、坑洞、空中翻滾與落地角度判定
- **障礙物**：巨石與尖刺（高速撞上會摔車，減速通過只顛簸扣分）、泥沼（減速）
- **加成道具**：金幣（分數）、氮氣罐（加速資源）、護盾（抵擋一次傷害）、加速板
- **競技元素**：即時名次／落後距離、對手位置箭頭、賽程進度條、三回合制對決、落後方追趕補給
- **成就系統**：15 項成就，跨場次記錄於 `save_data.json`
- **音訊**：程序化合成的選單／比賽背景音樂、12 種音效與隨車速變檔的引擎聲，不需任何外部音檔

## 執行方式

需先安裝 [uv](https://docs.astral.sh/uv/)。

```powershell
uv sync
uv run python -m motoduel
```

或直接雙擊 `play.bat`。

啟動時會顯示「音效合成中…」，約 1～2 秒完成音訊合成後進入主選單。

## 操作說明

### 主選單

- `↑` / `↓`（或 `W` / `S`）：選擇項目
- `←` / `→`（或 `A` / `D`）：切換電腦難度（游標停在「單人模式」時）
- `空白鍵` / `Enter`：確認
- `ESC`：離開遊戲

### 賽中

| 動作 | 玩家 1 | 玩家 2（雙人模式） |
|------|--------|--------|
| 油門 | `W` 或 `↑` | `↑` |
| 煞車／後退 | `S` 或 `↓` | `↓` |
| 空中後傾／前傾 | `A` / `D` 或 `←` / `→` | `←` / `→` |
| 氮氣 | 左 `Ctrl`（單人模式亦可用右 `Ctrl`） | `/`（或數字鍵盤 `/`） |

> 單人模式中，玩家 1 可同時使用 WASD 或方向鍵操作。

其他按鍵：

- `空白鍵`：進入下一回合／確認
- `P`：賽中暫停
- `R`：重跑本回合
- `M`：音效與音樂開關（靜音）
- `F`（或 `F11`、`Alt` + `Enter`）：全螢幕／視窗切換
- `ESC`：返回上一層／離開遊戲

## 全螢幕模式

按 `F`（也支援 `F11` 與 `Alt` + `Enter`）可隨時切換全螢幕，選單、賽中、暫停畫面皆可使用。

- 採**獨佔全螢幕**：顯示器解析度會切換為 1280×720，畫面填滿整個螢幕且不縮放，
  維持像素銳利與最低輸入延遲。
- 若顯示器不支援 1280×720，會自動改用 `SCALED` 全螢幕（維持 1280×720 邏輯畫布，
  由 SDL 等比縮放），不會因切換失敗而崩潰。
- 全螢幕與靜音偏好會寫入 `save_data.json`，下次啟動自動套用。
- 全螢幕時滑鼠游標自動隱藏。

## 輸入法相容性

中文輸入法（如微軟注音）在啟用狀態下會攔截空白鍵與英數鍵，導致遊戲收不到按鍵。
遊戲啟動時會呼叫 `pygame.key.stop_text_input()` 停用視窗的文字輸入，避免此問題；
另外也保留一條備援路徑：若系統仍只送出文字輸入事件，收到空白字元時同樣視為按下空白鍵。
每次切換全螢幕都會重建顯示模式，因此切換後會再次停用文字輸入，確保問題不會復發。

## 難度說明（單人模式）

| 難度 | 說明 | 電腦約略完賽時間 |
|------|------|------------------|
| 簡單 | 對手保守駕駛、少用氮氣，空中姿態常有失誤 | 約 47～51 秒 |
| 普通 | 對手全速前進、會前瞻減速閃避危險 | 約 40～44 秒 |
| 困難 | 對手幾乎不失誤、積極用氮氣與翻滾得分 | 約 35～42 秒 |

## 遊戲規則

1. 一場對決固定三回合，每回合為一條新隨機賽道（賽道長度 22000 px）。
2. 先抵達終點者贏得該回合；若無人完賽，以行進距離較遠者勝。
3. 首位完賽後，另一位玩家有 15 秒寬限時間完賽。
4. 回合勝場數較多者贏得整場對決；平手時比較累計分數。
5. 上一回合落後者，下一回合可獲得額外起始氮氣（追趕補償）；賽中落後超過 900 px 時氮氣回復加快。
6. 單人模式中，電腦對手不會解鎖成就，成就只計玩家 1 的表現。

## 音訊設計

所有聲音皆於啟動時以純 Python 即時合成（不使用 numpy，也不需外部音檔）：

- **背景音樂**：選單曲（10.8 秒循環）與比賽曲（Am–F–C–G，150 BPM，6.6 秒循環），含貝斯、和弦、主旋律與鼓組
- **音效**：金幣、氮氣、護盾、加速板、摔車、翻滾、完賽、倒數嗶聲、起跑、選單、成就解鎖、顛簸共 12 種
- **引擎聲**：5 段不同基頻的無縫循環音，依車速自動換檔，鬆油門時降低音量

無音效裝置時會自動停用音訊，遊戲仍可正常進行。按 `M` 隨時靜音。

## 專案結構

```
motoduel/
  config.py        # 物理、計分、畫面等全域參數
  terrain.py       # 程序化地形、障礙物與道具生成
  entities.py      # 機車物理模擬與特效
  ai.py            # 電腦車手（落地預測、姿態控制、危險前瞻）
  audio.py         # 程序化音樂／音效合成與播放管理
  achievements.py  # 成就定義與存檔
  render.py        # 字型、世界渲染與 HUD
  game.py          # 狀態機、輸入、賽事邏輯
tests/
  smoke_test.py    # 無頭煙霧測試（物理／互動／AI／音訊／輸入／流程／繪製）
  shot.py          # 產生畫面截圖供人工檢視
  live_check.py    # 開真實視窗檢查 FPS 與音訊通道
```
